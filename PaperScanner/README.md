# Paper Scanner (Android)

Scans paper of any size or colour, removes shadows, and saves PDFs to Downloads.

## Get the APK (free, no software needed)
1. Create a free account at github.com and make a new repository.
2. Upload all files in this folder (keep the `.github` folder).
3. Open the **Actions** tab. The "Build APK" job runs automatically (about 5 minutes).
4. Open the finished run, download **PaperScanner-apk**, unzip it, and copy the .apk to your phone.
5. On the phone, open the .apk and allow "Install unknown apps" when asked.

## Or build with Android Studio
Open this folder in Android Studio, then Build > Build APK(s).
